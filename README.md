🛒 Amazon Price Tracker

A Python script that tracks the price of a product on Amazon and sends you an email alert when the price drops below your desired threshold.

⸻

🚀 Features
	•	✅ Scrapes real-time product price from Amazon
	•	✅ Compares price with your desired target
	•	✅ Sends an email notification if the price drops
	•	✅ Uses BeautifulSoup for scraping and SMTP for email alerts
	•	✅ Easy to customize for any product

⸻

🛠️ Technologies Used
	•	Python 3
	•	Requests – for fetching product page
	•	BeautifulSoup (bs4) – for parsing HTML
	•	lxml – fast HTML parser
	•	smtplib – for sending emails
	•	dotenv – to keep your credentials safe
